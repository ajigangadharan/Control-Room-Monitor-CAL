Control Room Video Wall Monitor Calculator and sequence simulator

A modern, mobile-ready web application for designing and calculating video wall monitor requirements in security control rooms. Built as a single-file HTML application with real-time calculations, interactive sequence simulation, and SIRA compliance checking.

Features:
•	Real-time Monitor Calculation**
•	Input total cameras and define priority split (Percentage or Fixed Quantity)
•	Automatic calculation of Static vs Sequence cameras

Flexible Monitor Configuration:
•	Multiple grid layouts: 4x4, 5x5, 6x6, 8x8
•	Monitor sizes from 21" to 55"
•	Live total monitor quantity calculation

Interactive Camera Sequence Simulation:
•	Animated sequence view with configurable dwell time
•	Color-coded cycling through camera groups
•	Real-time visual representation of video wall layout

SIRA Compliance Check:
•	Automatic tile dimension calculation (mm)
•	Warning system for non-compliant tile sizes (Minimum: 120x67mm)

Project Management:
•	Save/Load configuration (JSON)
•	Professional printable report generation
•	Project name tracking

Fully Responsive Design:
•	Optimized for desktop and mobile devices
•	Touch-friendly interface

Quick Start
•	Enter your Project Name
•	Input Total Cameras
•	Choose priority method (Percentage or Fixed Quantity)
•	Select desired Split (N×N)and Monitor Size
•	View live results and compliance status
•	Use the Sequence View tab to simulate camera cycling
